jr-setup-ui

一行指令裝好工作坊需要的環境。不需要先裝任何東西。

macOS

打開「終端機」（Terminal），貼上這一行，按 Enter：

curl -fsSL https://musereed.github.io/jr-setup-ui/setup.sh | bash
  1. 沒有 Node.js 就自動安裝（會要你的 Mac 密碼）
  2. 沒有 Homebrew 就自動安裝（要跑幾分鐘）
  3. 裝完自動打開嚮導網頁

Windows

打開「PowerShell」，貼上這一行，按 Enter：

irm https://raw.githubusercontent.com/museReed/jr-setup-ui/main/docs/setup.ps1 | iex
  1. 沒有 Node.js 就自動安裝（透過 winget）
  2. 裝完自動啟動嚮導
  3. 複製終端機印出來的網址，貼到瀏覽器打開

卡住了怎麼辦

嚮導裡每一張卡的右上角都有一顆 鈴鐺。在卡住的那一張按它，它會把那一步的資訊整理好、開一個 填好的回報頁面——你看過內容、確定沒問題，再按 GitHub 的送出。

  1. 不會替你送出，也不會在你不知情的情況下上傳任何東西
  2. 家目錄會換成 ~，但送出前還是自己看一眼
  3. 也可以直接開：回報區

嚮導只跑在你自己的電腦上（只監聽 127.0.0.1），這個網站不會、也沒辦法 連到你的電腦。原始碼：github.com/museReed/jr-setup-ui
