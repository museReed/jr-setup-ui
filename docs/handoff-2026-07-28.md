## VM 上怎麼跑

**Windows（PowerShell）**

```powershell
winget install --id OpenJS.NodeJS.LTS -e --source winget --accept-source-agreements
# 裝完關掉 PowerShell 重開
cd ~
Invoke-WebRequest -Uri https://github.com/museReed/jr-setup-ui/archive/refs/heads/feature/install-buttons.zip -OutFile jr.zip
Expand-Archive jr.zip -DestinationPath . -Force
node jr-setup-ui-feature-install-buttons\bin\jr-setup-ui.js
```

**macOS**：先從 nodejs.org 裝 `.pkg`，然後 `curl -L -o jr.zip <同一個網址>`、
`unzip -o jr.zip`、`node jr-setup-ui-feature-install-buttons/bin/jr-setup-ui.js`。

Windows 不會自動開瀏覽器（複製終端機印的網址）；macOS 會。

## 架構要點

- **零相依 Node**，只監聽 `127.0.0.1`，啟動產生一次性 token，所有請求都要帶
- 可執行的動作是**寫死在本機的白名單**，網路端只傳代號
- agent 動作跑在 `~/.jr-setup/workdir`，不吃同學專案的脈絡（也大幅省 token）
- 每個 agent 動作宣告唯讀或可寫；自由輸入預設唯讀，開關打開才提升
- Windows 每次檢查前**從登錄檔重讀 PATH**，剛裝好的東西立刻叫得動

## Windows 踩過的坑（全部有迴歸測試）

| 坑 | 症狀 | 修法 |
|---|---|---|
| 子程序 stdin 沒關 | claude 白等 3 秒、**codex 完全卡死** | `stdio: ["ignore", ...]` |
| `--allowedTools` 是變長參數 | 把 prompt 一起吃掉 | 逗號串成單值 + `--` 收尾 |
| `.cmd` 不能直接 spawn | `spawn EINVAL` | 繞 `cmd.exe /d /s /c` |
| cmd.exe 找不到指令回 1 不是 9009 | 未安裝顯示成「檢查失敗」 | 改判「沒 stdout 又非零」 |
| 上面那條判準套到登入探測 | **未登入顯示成「需要先安裝」** | 只在版本探測啟用 |
| 開視窗的程序繼承管線不放 | `close` 不觸發，UI 永遠卡在「登入中…」 | `stdio:"ignore"` + detached + 立刻回 done |
| winget 沒指定 `--source` | msstore 憑證失敗導致整個裝不了 | `--source winget` + 自動接受條款 |
| winget「已安裝」回非零 | 顯示成安裝失敗 | 辨識 `0x8A15002B` 等良性碼 |

**貫穿全部的教訓**：函式「回傳形狀對」不等於「值是對的」。這些坑沒有一個能被
只驗形狀的測試抓到——**每一個都是在真機實跑才浮現的**。
