# copy-studio

編「學生要自己動手」那幾格的操作步驟與截圖。寫進 `content/`，改完 `git status` 就看得到動了哪幾個檔。

```
node tools/copy-studio/server.mjs
```

開 <http://127.0.0.1:4200/>（mac 會自己開瀏覽器，加 `--no-open` 不開）。

## 三件事

**改文案**　左邊挑一份，右邊直接打字。**沒有存檔按鈕**——停手 0.6 秒就寫進檔案，右上角會說「已寫進檔案」。要求人記得存檔，人就會忘記存檔。

**放截圖**　每一格可以選「不放畫面 / 用畫的 / 要截圖」。選「要截圖」會出現佔位框，把圖拖進去就存好了——**檔名是系統算的**，不用自己命名（規則見 `docs/walkthrough-architecture.md`）。

**看還缺哪些**　左邊那顆「還缺哪些截圖」列出所有標成「要截圖」但檔案還不在的格子，帶上該存成什麼名字、要拍什麼。

## 能畫的就不要拍

「用畫的」有五種：終端視窗、mac 的 Dock、Windows 工作列、嚮導的卡片、瀏覽器視窗。

畫的不會過期——Claude Code 改版、按鈕搬家，截圖就錯了，而畫面上一切正常，沒有任何測試抓得到。雙平台三語也只要換字串，不用出十二份。

真的非拍不可的（系統偏好設定、Finder、第三方網站）才用「要截圖」，那些畫面本來就幾年不變。

## 新增了一格要教學的？

`VERIFICATION` 加了眼睛項、或 `CARD_GATES` 加了人工項之後：

```
node tools/copy-studio/seed.mjs
```

它照真的設定算出該有哪幾份，只補新的，**既有的檔案一個都不動**。加 `--list` 會把清單印出來。

## 檔案落點

```
content/walkthroughs/<id>.json     步驟與文案
content/shots/<id>/<檔名>.png       真的要拍的那些
```

## 給改這支工具的人

- 零依賴，跟整個 repo 一樣。學生端永遠不跑 `npm install`。
- 只綁 `127.0.0.1`：它會寫檔案，不該被同網段的人打得到。
- 檔名在 `server.mjs` 與 `public/studio.js` 各算一次。**這是刻意的**——前端要在圖還沒上傳前就顯示「它會存成什麼名字」，而後端不能相信前端算的名字。兩邊改要一起改。
- `public/mocks.js` 只回字串、不碰 DOM：嚮導的彈窗之後要用同一支畫同樣的畫面。
